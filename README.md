# meeKeyboard

An on-screen keyboard for Android — English + Bengali, with meeEL integration coming.

**Made by [mee Innovations](https://github.com/meeEL-Code).**

## Features

- QWERTY (English) + Bengali layout
- Swipe typing
- Word suggestions & auto-correct (English + Bengali)
- Long-press letter for symbols (Gboard-style)
- Long-press backspace for fast delete
- Clipboard panel with history (Recent + Pinned)
- Emoji panel (500+ across 8 categories)
- Dark / Light / Blue themes
- Custom backgrounds — 6 presets + pick from gallery
- Shift + Caps lock
- Cursor arrows
- Haptic + sound feedback
- User dictionary — learns from your typing

## Install

Download the latest APK from [Releases](https://github.com/meeEL-Code/meeel-keyboard/releases/latest).

1. Open the APK on your phone
2. Allow installation from unknown sources
3. Settings → Languages → Keyboards → **meeKeyboard** → ON
4. Pick meeKeyboard from the keyboard switcher

## Develop

Built with Kotlin + Gradle. CI builds APK via GitHub Actions.
